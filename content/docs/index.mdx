# 下载与安装

## Github Releases

最新版本请以 Github Releases 为准，下载连接: [https://github.com/ComeixAlpha/Colorify7/releases](https://github.com/ComeixAlpha/Colorify7/releases)

<Steps>

<Step>
  找到最新的发布版本，其会被标记为{" "}
  <span className="text-green-300">Latest</span>
</Step>

<Step>
根据你的平台选择你要下载的版本

对于 Windows 用户，请下载：`colorify_7.x.x_x64-setup.exe`

对于 Android 用户，清下载：`app-universal-release.apk`

</Step>

<Step>
对于 Windows 用户，根据安装向导安装即可

对于 Android 用户，请打开 Colorify，并授予其所有请求的权限

</Step>

</Steps>

## 蓝奏云

为了照顾部分用户无法访问 Github 的情况，Colorify 也提供了蓝奏云的下载链接，下载连接请参考[我在 Bilibili 发布的视频](https://www.bilibili.com/video/BV1tehN6VECg/)的简介

<Callout type="warning" title="警告">
  蓝奏云的下载链接可能会过期，或是落后，请以 Github Releases 为准
</Callout>
